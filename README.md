# Aplikasi Laporan Masyarakat

Project UAS Pemrograman Mobile – Aplikasi Laporan Masyarakat (Flutter).

## Anggota Kelompok
- Ni Wayan Anggi (2301010056)
- Ni Putu Pudja Sari Arlina (2301010051)


## Deskripsi Singkat
Aplikasi untuk melaporkan kejadian kebakaran, medis, dan pencurian, lengkap dengan data pelapor, lokasi, waktu, dan foto bukti.

## Fitur Utama
- Form laporan kebakaran, medis, pencurian.
- Upload foto bukti laporan.
- Menyimpan riwayat laporan.

## Teknologi
- Flutter
- HTTP Request
- Camera
- Geolocation
